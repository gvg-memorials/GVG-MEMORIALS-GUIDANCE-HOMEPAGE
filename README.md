# GVG Memorials Guidance Homepage

Standalone guidance-first homepage concept for GVG Memorials.

This version is separate from the `GVG-WEBSITE-LIQUID-GLASS` design concept repo. It uses a warm editorial memorial-park hero image, GVG logo assets, and copy based on public business research: family-owned service, 20+ years of experience, custom memorial guidance, cemetery-aware planning, and local Oxnard/Ventura County support.

## Files

- `index.html` - static homepage
- `styles.css` - full responsive visual system
- `assets/` - GVG logo and homepage hero image

## Preview

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 4173
```

Then visit `http://127.0.0.1:4173/`.
